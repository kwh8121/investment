## converge 잔여 갭

`/speckit-converge`가 이 절 아래에 잔여 갭을 추가한다. 추가된 항목은 Linear 이슈 또는 계획 수정으로 옮긴 뒤 처리 결과를 적는다.

2026-09-15 현재 이 파일에는 실제 `/speckit-converge` 실행 출력이 없다. 따라서 "새 잔여 갭 없음"을 converge 실행 결과로 주장하지 않으며, 잔여 갭 판정은 다음 실제 converge 실행 또는 사람 리뷰에서 별도 기록한다.
