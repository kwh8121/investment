# DG1 데이터·권한 Reality Check — Gate 판정 기록

> Gate: DG1 데이터·권한 Reality Check
> 판정일: 2026-09-07
> 판정: Conditional Go / 한국 시장 한정
> Owner (담당): 제품 책임자
> Approver (승인): 검토자

## 1. 판정 근거

- `docs/references/dg1-data-rights-evidence-register-2026-09-07.md` 6.2절에서 2026-09-04 기준 한국 고정 표본 5개(`069500`, `102110`, `229200`, `360750`, `133690`)의 키움·KRX 종가, 거래량, NAV가 모두 일치했다.
- KRX Open API `etf_bydd_trd`는 `basDd` 기준일 요청으로 ETF 일별 가격, NAV, 거래량과 기초지수 필드를 제공하며, 2026-09-07 수집에서 HTTP 200과 1,167개 ETF 행을 반환했다. 인증키 값은 기록하지 않았다.
- KRX Open API 약관은 비상업적 이용만 허용하고 KRX 제공 정보의 제3자 제공을 금지한다. 현재 PRD의 개인·비상업·비공개 내부 사용 경계에는 부합하며, 공개 표시·제3자 공유·재배포·상업 이용은 승인 범위에서 제외한다.
- Task 002·003의 키움 증거는 한국 ETF 5개 이상의 목록·일봉, 연속조회와 오류·재시도 관찰을 제공한다. 원본 응답과 정규화 결과의 영구 저장 계약은 Task 004에서 정의한다.

## 2. 승인 범위

- 한국 ETF만 대상으로 Task 004와 이후 단일 ETF 종단 파이프라인을 진행할 수 있다.
- 국내 가격·거래량·NAV는 키움 수집값을 KRX 같은 거래일 값으로 대조한다.
- 사용은 개인·비상업·비공개 내부 분석으로 한정한다. 공개 화면, 제3자 공유, 재배포, 상업 이용은 이 판정으로 승인하지 않는다.
- 원본 스냅샷, 출처, `as_of`, 수집 시각, 정규화 결과와 품질 상태를 함께 보존하되, 저장·공유 전에 API 키·토큰·계정 식별자를 제거하거나 마스킹한다.

## 3. 미충족 항목과 제외 범위

- 미국 ETF는 가격 보조 대조, 환율, 분배금, 수정주가, 거래일·휴장일 근거가 미충족이므로 `No-Go`다. 미국 시장은 Task 004 이후 구현·수집 범위에서 제외한다.
- 한국 ETF의 수정주가, 분할·병합·분배락 처리 근거는 고정 1일 표본으로 확정되지 않았다. Task 004 데이터 계약에서 원본·정규화 분리와 결측·이상치 처리 규칙을 정의하고, 추천·성과 계산 전 검증한다.
- KRX 인증키의 보유와 단일 성공 호출은 해당 서비스의 기술적 접근 증거일 뿐, 공개·재배포·상업 이용 권한의 근거가 아니다.

## 4. 예외 및 만료일

- 예외: 미국 시장 제외, 한국 시장의 수정주가·법인행사 처리 보류.
- 예외 만료일: 2026-09-21. 이 날짜까지 미국 보완 증거 또는 한국 처리 규칙을 제출하지 못하면 조건부 범위를 재검토한다.

## 5. 재검토 트리거

- 미국 ETF를 수집·표시·계산 범위에 포함하려는 경우
- 한국 ETF의 수정주가, 분할·병합·분배락, 3영업일 연속 결측 또는 ±30% 이상 변동이 발생한 경우
- 공개 표시, 제3자 공유, 재배포 또는 상업 이용을 제안하는 경우
- KRX 또는 키움의 약관, 인증·접근 범위, API 필드 또는 데이터 품질이 변경되는 경우
