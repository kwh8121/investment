# Task 008 — 소규모 간이 백테스트 증거

## 실행 범위

- DG1 승인 범위의 한국 ETF 5개(`069500`, `102110`, `229200`, `360750`, `133690`)를 전략별로 실행한다.
- Momentum과 Oversold는 같은 관측 집합을 사용하되 전략별로 독립 실행한다.
- 전략별 상위 퍼센타일 컷과 유동성 최소값을 조합해 민감도를 계산한다.
- 한국 ETF는 KRW 기준으로 계산하며 환율 기여도는 0으로 확인한다. 미국 ETF 환율 검증은 DG1 No-Go 해소 전 범위에 포함하지 않는다.
- 선택 종목의 시장·산업·기간 집중도를 과적합 경고로 기록한다.

## 산식과 판정

- `KRW 총수익률 = (1 + 현지 가격수익률) × (1 + 환율수익률) × (1 + 분배금수익률) - 1`
- 변별력은 선택군 평균 KRW 수익률과 유효 유니버스의 벤치마크 평균 KRW 수익률의 초과수익으로 기록한다.
- 민감도 조합은 퍼센타일 `90/95/97.5`와 유동성 `60/80`이다.
- 단일 산업·시장·기간에 선택군이 집중되면 과적합 경고를 낸다.

## 실제 기간 검증

- DG1 승인 한국 ETF 5개와 KOSPI200의 2026-08-03~2026-09-08 일봉을 키움 REST 조회 전용 명령으로 수집했다.
- 실제 가격수익률과 KOSPI200 대비 초과성과는 `docs/plan/gates/DG2-strategy-validation.md`에 기록했다.
- 현재 키움 일봉 응답만으로는 분배금 이력과 전략별 펀더멘털 입력을 확정할 수 없으므로, 이 결과는 가격·벤치마크·시점 누수 검증으로 한정한다.
