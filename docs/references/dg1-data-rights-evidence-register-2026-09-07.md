# DG1 데이터·권한 Reality Check — 증거 등록부

> 확인일: 2026-09-07
> 관련 Task: `docs/ROADMAP.md` Task 003
> 상태: 증거 수집 중 — 개인 비상업·비공개 내부 사용 정책에 따라 공식 권한 서면은 DG1 차단 조건이 아님. 이 문서는 DG1 판정 문서가 아니며 Go / Conditional Go / No-Go 판정을 포함하지 않음

## 1. 목적과 판정 경계

이 문서는 Task 003의 소스별 데이터 가용성·운영 경계 확인을 위한 근거를 모은다. MVP는 개인의 비상업적·비공개 내부 사용으로 한정하므로, 공식 권한 서면의 확보는 DG1 통과 조건이 아니다. 공개 표시, 제3자 공유, 재배포 또는 상업적 이용을 제안할 때만 구현 전에 별도 약관·권한 검토와 PRD 변경이 필요하다. 실제 DG1 판정, 미충족 항목, 예외 만료일과 재검토 날짜는 완료 시에만 `docs/plan/gates/DG1-data-rights.md`에 기록한다.

`docs/ROADMAP.md` Task 002의 실데이터 호출 증거는 이미 한국·미국 ETF 각 5개 이상, 목록·일봉, 연속 조회와 필드 매핑을 확인했다. 본 등록부는 그 증거를 재복제하지 않고, 사용·저장·내부 표시·재배포 권한과 가격·환율·분배금 품질 검증의 남은 작업을 정리한다.

#### 6.3.1 보충 소스 측 확인

- `usa10104`의 AMEX ETF·ETN 목록 응답에서 고정 미국 표본 `AAAA`, `AAAU`, `AAOG`, `AAOX`, `AAOZ`는 모두 `stex_tp: NA`, `stk_cd`가 표본 티커와 동일, `etn: N`, `mkgb: AMEX`로 반환됐다. 로컬 명세는 종목코드를 `code`로 표기하지만 실제 CLI JSON 응답은 `stk_cd`를 사용하므로, 정규화 필드명은 명세·실응답 불일치가 해소될 때까지 확정하지 않는다.
- `ka40004` ETF 전체 시세의 현재 목록 1페이지는 `dvid_bf_base`, `pred_dvida`, `nav` 필드를 포함해 반환됐다. 그러나 이 응답은 현재 시점의 목록이며 고정 2026-09-04 표본을 포함하지 않았으므로, 고정 표본의 해당 거래일 분배금·NAV 증거 또는 분배금 결측 의미의 근거로 사용하지 않는다.

### 6.5 필드 처리 원칙

- `upd_stkpc_tp`, `upd_rt`, 분배금, 환율, NAV, 거래량 중 소스가 제공하지 않거나 의미를 확인할 수 없는 필드는 `nullable` 또는 제외 후보로 기록한다.
- 분할·병합·분배락, 휴장, 3영업일 이상 연속 결측, 전일 대비 ±30% 이상 변동은 값만 비교하지 않고 이벤트·결측 사유와 함께 기록한다.
- API가 제공하는 수익률은 비교 기준이 아니다. 공식 성과는 일별 가격·환율·분배금의 기준일이 일치할 때만 자체 계산한다.
- 원본 응답 또는 작업 로그를 보관할 때는 인증 헤더, API 키, Bearer 토큰, 쿠키 및 계정 식별자를 저장·공유 전에 제거하거나 마스킹한다.
