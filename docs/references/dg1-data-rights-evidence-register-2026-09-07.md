# DG1 데이터·권한 Reality Check — 증거 등록부

> 확인일: 2026-09-07
> 관련 Task: `docs/ROADMAP.md` Task 003
> 상태: 증거 수집 중 — 개인 비상업·비공개 내부 사용 정책에 따라 공식 권한 서면은 DG1 차단 조건이 아님. 이 문서는 DG1 판정 문서가 아니며 Go / Conditional Go / No-Go 판정을 포함하지 않음

## 1. 목적과 판정 경계

이 문서는 Task 003의 소스별 데이터 가용성·운영 경계 확인을 위한 근거를 모은다. MVP는 개인의 비상업적·비공개 내부 사용으로 한정하므로, 공식 권한 서면의 확보는 DG1 통과 조건이 아니다. 공개 표시, 제3자 공유, 재배포 또는 상업적 이용을 제안할 때만 구현 전에 별도 약관·권한 검토와 PRD 변경이 필요하다. 실제 DG1 판정, 미충족 항목, 예외 만료일과 재검토 날짜는 완료 시에만 `docs/plan/gates/DG1-data-rights.md`에 기록한다.

`docs/ROADMAP.md` Task 002의 실데이터 호출 증거는 이미 한국·미국 ETF 각 5개 이상, 목록·일봉, 연속 조회와 필드 매핑을 확인했다. 본 등록부는 그 증거를 재복제하지 않고, 사용·저장·내부 표시·재배포 권한과 가격·환율·분배금 품질 검증의 남은 작업을 정리한다.

| 공공데이터포털 금융위원회 증권상품시세정보 | ETF 가격 조회 REST API, JSON/XML 응답, 개발 계정 일 10,000회 및 생산 계정 증설 요청 경로가 공개되어 있다.                                                                                         | 데이터셋 페이지는 이용허락 범위를 `limitless`로 표시한다. 다만 포털 정책은 제3자 권리가 포함된 공공데이터에는 권리자의 적법한 허가가 필요하고, 제공 데이터의 공공누리 표시 범위를 따라야 한다고 명시한다.                                     | 개인의 비상업적·비공개 내부 분석과 보조 대조 후보로 사용한다. 공개 표시·제3자 공유·재배포는 제외한다.                      |
| OpenDART                                   | 회원·인증키 기반 OpenAPI가 있고, 공시 검색·기업개황·공시 원본 파일 API를 제공한다.                                                                                                                | 이용약관 제11조는 원칙상 무료라고 정하고, 제16조는 API·관련 프로그램 저작권이 금융감독원에 있으며 약관에 없는 저작권 사항은 저작권법·공공데이터법을 따른다고 정한다.                                                                          | ETF 일별 가격의 대체 소스가 아니다. 운용사·기초자산 관련 공시 보조 근거 후보로만 보류하며, 개별 활용 범위는 별도 확인한다. |

## 5. 다음 실행 순서

1. 개인 내부 사용 경계를 벗어나는 공개 표시·제3자 공유·재배포·상업 이용 요구를 수용하지 않는다.
2. 한·미 ETF 각 5개 표본의 가격·환율·분배금·거래일을 대조한다.
3. 미확정 필드와 결측·이상치 규칙을 확정한 뒤 DG1 판정 제출물을 작성한다.
